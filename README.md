# 计算机系统基础 (Introduction to Computer System)

这是我在武汉大学2025春季学期学习计算机系统基础课程的学习记录和资料整理。

## 课程内容

本课程基于《深入理解计算机系统》（CSAPP）教材，主要学习了以下章节：

1. 计算机系统漫游 (A Tour of Computer Systems)
2. 信息的表示和处理 (Representing and Manipulating Information)
3. 程序的机器级表示 (Machine-Level Representation of Programs)
5. 优化程序性能 (Optimizing Program Performance)
7. 链接 (Linking)
8. 异常控制流 (Exceptional Control Flow)
10. 系统级I/O (System-Level I/O)

## 完成的实验

在课程学习过程中，我完成了以下实验：

1. C Lab - C语言基础实验
2. Data Lab - 数据实验，位操作和浮点数运算
3. Bomb Lab - 拆弹实验，反汇编和调试
4. Attack Lab - 攻击实验，缓冲区溢出
5. Performance Lab - 性能实验，代码优化
6. Linking Lab - 链接实验，链接器与目标文件
7. PIC Lab - 位置无关代码实验
8. Shell Lab - Shell实验，实现简单的Unix Shell
